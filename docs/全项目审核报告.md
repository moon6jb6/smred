## 一、主页 index.html

### 模块概述
电影感开场：黑屏数字倒计时（86,000→7,000）→ 叙事文字渐显 → 点击进入 → 土路+6个路标导航。每个路标对应一个模块，点击后触发胶片转场。

### 核心特点
- **数字倒计时动画**：easeOutExpo 缓动，数字从 86,000 降到 7,000（长征出发→到达人数）
- **CSS 土路**：旋转 -18 度的棕色渐变条，年份标签从 1840 到 2026
- **6 个路标**：沿土路排列，hover 时金色发光脉冲，点击触发 filmstrip.js 转场

## 二、filmstrip.js（共享转场工具）

### 模块概述
全站共享的页面转场系统。两个核心函数：
- `filmstripTransition(url, narrative)` — 创建 8 条黑色横条 scaleX 展开动画，存储叙述文字到 sessionStorage，700ms 后跳转
- `checkNarrativeTransition(callback)` — 页面加载时检查 sessionStorage，如有叙述文字则全屏黑底白字显示 2.5 秒后淡出

### 核心特点
- **胶片转场**：8 条横条依次展开（60ms 间隔），模拟电影胶片效果
- **叙述叠加层**：转场后显示叙事文字，增强沉浸感
- **响应式**：768px / 480px 断点适配
- **CSS 注入**：通过 `injectFilmstripCSS()` 动态注入所有样式

### 待修复问题

| # | 问题 | 详情 |

## 三、mod1 — 重走长征路

### 模块概述
全屏滚动叙事（6 个阶段），CSS scroll-snap 强制对齐。每个阶段 100vh，展示长征关键节点。

### 核心特点
- **6 阶段叙事**：出发(1934) → 湘江(1934) → 遵义(1935) → 泸定桥(1935) → 雪山草地(1935) → 到达(1936)
- **湘江分支选择系统**：滚动到第 2 阶段时数字从 86,000 动画到 50,000，弹出选择面板（"正面强渡" vs "轻装急行"）
  - 两条路径都导向同一历史结局（30,000 人幸存），但情感体验不同
  - "攻击"路径：800 粒子爆炸 + 屏幕震动 + 血色洗屏
  - "撤退"路径：渐隐效果
- **Canvas 粒子系统**：粒子从中心爆发，60fps 渲染
- **进度条 + 阶段指示点**：顶部进度条 + 右侧导航点
- **sessionStorage 状态**：记住用户是否已做过湘江选择
