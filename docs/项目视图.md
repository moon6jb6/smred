## 三、技术架构

```
项目1/
├── index.html                    # 首页（开场动画 + 15模块导航）
├── page/
│   ├── filmstrip.js              # 胶片转场引擎（全局共享）
│   │
│   ├── longfight_rouit_mod1/     # mod1 — 内联CSS/JS
│   ├── chess_mod2/               # mod2 — 独立CSS/JS
│   ├── timeriver_museum_mod3/    # mod3 — 内联JS
│   ├── sacrifice_mod4/           # mod4 — 内联JS + 独立CSS
│   ├── greatman_mod5/            # mod5 — 内联JS
│   ├── china_power_mod6/         # mod6 — 内联JS + 独立CSS
│   ├── mod7/ ~ mod15/            # mod7-15 — 独立CSS/JS
│
└── docs/                         # 设计文档（8份）
```

### 关键技术点

- **转场系统**: `filmstrip.js` 提供胶片风格页面切换动画
- **叙事守卫**: `checkNarrativeTransition()` 全局函数，处理模块间叙事衔接
- **音频引擎**: `AudioEngine` Web Audio API 合成音效（心跳、环境音、摩尔斯码）
- **存储层**: `Storage.setModuleProgress()` localStorage 封装
- **无障碍**: ARIA dialog/progressbar + 焦点管理 + `prefers-reduced-motion` + 键盘导航
- **安全**: innerHTML → DOM API 防 XSS，焦点陷阱防聚焦逃逸
- **性能**: Canvas DPI适配(devicePixelRatio)、resize防抖、动画降级

## 四、模块详情

### Mod1 — 重走长征路
- **类型**: 分支叙事冒险
- **规模**: 1314行（最大HTML）
- **玩法**: 20个关卡，每关面临生死抉择，选择影响后续路线和结局
- **特色**: 进度条追踪、多个结局分支、个人关联年份输入

### Mod2 — 纸上谈兵·象棋
- **类型**: 棋类AI对弈
- **规模**: 1022行HTML + 643行CSS + 1038行JS
- **玩法**: 30个残局关卡，逐步解锁，AI自动应棋
- **特色**: 吃子粒子特效、胜负弹窗、关卡选择面板、终局冲击动画

### Mod3 — 时间博物馆
- **类型**: 沉浸式探索
- **规模**: 1026行HTML
- **玩法**: 点击历史物件揭示背后故事，时间线导航
- **特色**: 隐藏手稿彩蛋、物件放大动效、出生年份关联

### Mod4 — 祭祀大典
- **类型**: 仪式体验
- **规模**: 1039行HTML
- **玩法**: 黑暗中逐步点亮剪影，祭奠革命先烈
- **特色**: 浮动引言系统、Canvas粒子光效、环境音氛围

### Mod5 — 三次选择·毛泽东
- **类型**: 历史决策模拟
- **规模**: 1033行HTML + 454行CSS + 409行JS
- **玩法**: 3次关键历史节点（秋收起义、遵义会议、抗美援朝），做出决策
- **特色**: Canvas粒子背景、因果分支、DPI自适应

### Mod6 — 中国力量
- **类型**: 数据可视化
- **规模**: 802行HTML + 415行CSS + 348行JS
- **玩法**: 拖动时间轴查看1949-2026数据变化
- **特色**: 数字滚动动画、颜色触发、70年全景一屏、个人年份关联

### Mod7 — 电报战士
- **类型**: 技能挑战
- **规模**: 468行JS
- **玩法**: 摩尔斯电码发报机，输入SOS等信息，速度评分
- **特色**: 实时声音反馈、发报动画、历史背景故事

### Mod8 — 暗线
- **类型**: 潜伏叙事
- **规模**: 471行JS
- **玩法**: 扮演地下工作者，传递秘密情报
- **特色**: 有限状态机驱动、紧张氛围、多结局

### Mod9 — 抉择电台
- **类型**: 声音叙事
- **规模**: 398行JS
- **玩法**: 电台播报历史事件，在关键时刻做出抉择
- **特色**: 音频驱动叙事、时间压力、多分支

### Mod10 — 历史显影
- **类型**: 图像交互
- **规模**: 383行JS
- **玩法**: 模拟老照片修复，滑动对比前后效果
- **特色**: 前后对比滑块、历史注释弹出

### Mod11 — 历史星图
- **类型**: 星空探索
- **玩法**: 星座代表历史事件，点击星座展开故事
- **特色**: Canvas星空渲染、星座连线动画

### Mod12 — 觉醒纪念碑
- **类型**: 集体纪念
- **玩法**: 用户可在纪念碑上献花留言
- **特色**: 纪念碑构建动画、用户互动

### Mod13 — 节拍革命
- **类型**: 音乐节奏游戏
- **玩法**: 跟随革命歌曲节奏打击
- **特色**: 节拍判定、分数系统、歌曲切换

### Mod14 — 最后一步
- **类型**: 仪式体验
- **规模**: 390行JS + 502行CSS
- **玩法**: 冲锋→倒下→纪念烈士→再冲锋的循环（3轮）
- **特色**: 心跳声效、血迹粒子、烈士真实事迹、用户姓名刻碑
- **数据**: 12位真实烈士（陈树湘、方志敏、杨靖宇、赵一曼等）

### Mod15 — 审判席
- **类型**: 辩论审判
- **规模**: 498行JS
- **玩法**: 历史人物站上审判席，收集证据，做出评判
- **特色**: 倒计时选择、统计展示、多结局

## 五、设计系统

### 色板
| 用途 | 色值 | 说明 |
|---|---|---|
| 背景 | `#0a0a0a` | 深黑 |
| 强调/标题 | `#c9a96e` | 金色 |
| 高亮 | `#ffd700` | 亮金 |
| 红方 | `#c0392b` / `#e74c3c` | 象棋红子 |
| 黑方 | `#1a1a2e` / `#2a2a4e` | 象棋黑子 |
| 成功 | `#2ecc71` | 绿色 |
| 警告 | `#e74c3c` | 红色 |
| 辅助文字 | `rgba(201,169,110,0.6)` | 半透明金 |

### 字体
- 主字体: Microsoft YaHei, Heiti SC, Arial
- 图标: Font Awesome 6.4.0

### 响应式断点
- `>768px`: 桌面端全尺寸
- `≤768px`: 棋盘缩放85%，面板纵向排列
- `≤480px`: 棋盘缩放65%，控制按钮横排
